數據來源 & 兜底

Open-Meteo 免費 API 能給：

· 天氣現象：WMO 天氣碼直接映射 晴 / 多雲 / 陰 / 霧 / 雨（小中大）/ 雷暴（雪、冰雹香港罕見，暫不做圖形）

· 風：wind_speed + wind_direction → 風力 + 風向（東北風 / 東南風…8 向，用文字標在圖旁）

· 晝夜：is_day（或 sunrise/sunset 換算）→ 白天太陽 / 夜晚月亮

⚠ 颱風等級不在 Open-Meteo 裡。 風球信號（一號 / 三號 / 八號 / 九號 / 十號）是香港天文台（HKO）的熱帶氣旋警告，得另接 HKO 警報源。

· 圖標只畫「颱風在轉」（紫色旋渦）；等級要顯示的話，用文字標在圖旁（如「八號風球」），不放進圖形裡。

兜底：加載中 / 請求失敗 / 座標缺 → 右上角直接留空，不塞問號或錯誤圖示。
