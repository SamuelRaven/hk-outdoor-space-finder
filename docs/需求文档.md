# 需求文档 — 香港公园推荐小程序

> 来源：`介绍.txt`（2026-08-08）

---

## 项目定位

一个移动端纯网页应用，用户通过网址或扫二维码在手机浏览器打开。帮助用户根据地区、时段、设施偏好筛选并推荐香港的户外公共空间/公园。

---

## 页面功能

### 第1页：首页

| 元素 | 说明 |
|------|------|
| 按钮1 | "户外公共空间 / 公园" → 跳转筛选页 |
| 按钮2 | "大自然徒步登山" → 弹出 toast "此房间还在装修中哦~"（暂不做） |

### 第2页：筛选页

| 筛选项 | 选项值 |
|--------|--------|
| 地区 | 港岛 / 九龙 / 新界 → 二级选择：18区具体分区 |
| 时间 | 清晨 / 上午 / 中午 / 下午 / 傍晚 / 夜晚 |
| 偏好设施 | 静态设施 / 动态设施 |
| 项目 | 根据偏好设施动态切换子选项 |

**项目子选项映射：**

| 偏好设施 | 项目可选值 |
|----------|-----------|
| 静态设施 | 植物及园景、历史特色、水景设施、教育及展览中心、宠物公园、动物公园及花园 |
| 动态设施 | 儿童游乐设施、模型车场/模型船区、滚轴运动设施、缓跑径/健身径、其他 |

**特殊按钮：**
- **GO!**（方形，占两行高度）：执行筛选，跳转结果页
- **盲盒**（右下角）：随机推荐一个公园

### 第3页：结果页

- 返回10个推荐公园
- 每个公园以卡片形式展示：名称、开放时间、1-2句介绍

### 第4页：盲盒结果页

- 文字："命运已掷出骰子，你今日要来......"
- 可选骰子滚动动画
- 展示1个随机公园卡片
