# 需求文档 — 香港户外空间推荐小程序

> 来源：`介绍.txt`（2026-08-08），2026-08-09 大幅更新

---

## 项目定位

一个移动端纯网页应用，用户通过网址或扫二维码在手机浏览器打开。帮助用户根据地区、偏好筛选并推荐香港的户外公共空间/公园及徒步山径。

---

## 页面功能

### 第1页：首页

| 元素 | 说明 |
|------|------|
| 按钮1 | "户外公共空间 / 公园" → 跳转公园筛选页 `#/filter` |
| 按钮2 | "大自然徒步登山" → 跳转徒步筛选页 `#/hiking-filter` |

### 第2页：公园筛选页

| 筛选项 | 选项值 |
|--------|--------|
| 地区 | 港岛 / 九龙 / 新界 → 二级选择：18区具体分区 |
| 时间 | 清晨 / 上午 / 中午 / 下午 / 傍晚 / 夜晚 |
| 公园类型 | 海濱長廊 / 市區公園 / 郊野綠地 / 主題園林 / 休憩花園 |
| 做点什么 | 散步看景 / 親子放電 / 運動出汗 / 寵物出行 / 安靜發呆 |

**特殊按钮：**
- **GO!**（红色方形，占两行高度）：执行筛选，跳转结果页
- **盲盒**（右下角）：随机推荐一个公园
- **收藏入口**（★）：查看已收藏的公园/山径

### 第3页：徒步筛选页

| 筛选项 | 选项值 |
|--------|--------|
| 地区 | 港岛 / 九龙 / 新界 → 二级选择：18区具体分区 |
| 难度 | 著波鞋就得 / 著行山鞋穩陣D / 著咩鞋都腳軟 |
| 氛围 | 山海之間 / 深山林蔭 / 水庫平湖 / 登頂大景 / 瀑布溪澗 / 歷史遺跡 |
| 路况 | 石屎路為主 / 山徑為主 / 樓梯為主 / 混合 |

**特殊按钮：**
- **GO!**（黄色方形，占两行高度）：执行筛选，跳转徒步结果页
- **盲盒**（右下角，蓝色主题）：随机推荐一条山径

### 第4页：公园结果页

- 返回最多10个推荐公园
- 每个公园以卡片形式展示：名称、地区标签、开放时间、1-2句介绍
- 顶部统合提示条（根据筛选条件生成）
- 点击卡片进入公园详情页

### 第5页：徒步结果页

- 返回最多10条推荐山径
- 每条山径以卡片形式展示：名称、路段、难度、时长距离、简介、贴士
- 顶部统合安全提示（根据筛选条件动态生成）
- 点击卡片进入山径详情页

### 第6页：公园盲盒页

- 文字："命运已掷出骰子，你今日要来……"
- 3D 骰子滚动动画
- 展示1个随机公园卡片（含贴士 + 命运骰子提示）
- 冷却系统：10次/10小时/localStorage 持久化

### 第7页：徒步盲盒页

- 文字："命运已掷出骰子，你今日要来……"
- 3D 骰子滚动动画
- 展示1条随机山径卡片（含贴士 + 命运骰子提示）
- 与公园盲盒共享冷却系统

### 第8页：公园详情页

- 路由：`#/park/{id}`
- 展示：名称、地区、类型、开放时间、最佳时段、活动标签 + 介绍卡片
- 智能内容生成：適合人群、打卡建議、裝備建議、出行貼士、沿途看點
- 右上角收藏星星（☆/★ 切换）

### 第9页：山径详情页

- 路由：`#/trail/{id}`
- 展示：名称、路段、地区、难度、全长、需时、风景标签、路况、简介、贴士
- 智能内容生成：適合人群、打卡建議、裝備建議、出行貼士、沿途看點
- 右上角收藏星星（☆/★ 切换）

### 第10页：收藏列表页

- 公园收藏：`#/fav-parks` — 已收藏公园卡片列表
- 山径收藏：`#/fav-trails` — 已收藏山径卡片列表
- localStorage 持久化，公园/山径分开存储
- 空状态提示

---

## 数据来源

- **公园数据**：基于香港康文署（LCSD）公园列表的公开信息，parkType 和 activityTypes 基于名称与描述文本推断（康文署网站被墙，无法逐一核实设施清单）
- **山径数据**：麦理浩径、衛奕信徑、港島徑、鳳凰徑官方分段 + 独立热门路线 + 郊遊徑/家樂徑，长度/时间/难度经官方资料交叉验证
