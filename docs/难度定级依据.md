# 难度定级依据

> 统一全部山径（含未来新增）的难度定级标准，保证**真实、准确、可追溯**。

---

## 1. 标准标尺：郊野樂行 5 星制（四维综合）

难度采用郊野樂行官方 5 星语义作为**唯一标尺**。官方星级是「長度 + 時間 + 總攀升 + 路面」四维综合评定：

| 星 | 官方语义 |
|----|---------|
| 1星 | 易行 |
| 2星 | 普通 |
| 3星 | 费力 |
| 4星 | 难行 |
| 5星 | 非常难行 |

> ⚠️ 注意区分：维基百科粤语页的「★/★★/★★★」是另一套 3 星制（易行/难行/極費力），**不可**混用。

## 2. 映射：5 星 → 鞋 metaphor

| 星 | `difficulty` 文案 |
|----|------------------|
| 1星 | `著波鞋就得` |
| 2星 | `著波鞋都頂得住` |
| 3星 | `著行山鞋穩陣D` |
| 4星 | `著行山鞋都腳軟` |
| 5星 | `著咩鞋都打嗮震` |

## 3. 三类路线及定级规则

| 类别 | 定级依据 | 优先级 |
|------|---------|--------|
| **A. 四大径分段**（麦理浩/衛奕信/港島/鳳凰，共 40 段） | 郊野樂行官方星级 | 官方 |
| **B. 官方郊遊徑/家樂徑/自然教育徑**（在郊野樂行目录内） | 郊野樂行官方星级 | 官方 |
| **C. 无官方星级路线**（独立名线、島嶼、非官方郊遊徑等） | 公开登山网站明确评级 | 见下 |

**C 类路线（无官方星级）的公开来源优先级：**

1. **优先**：先确认该路线是否其实在郊野樂行官方目录内（有些家樂徑/自然教育徑是官方的，只是名称略异）。
2. **其次**：公开登山网站明确难度评级 — Oasistrek（綠洲）、Hillmanblog、Fitz（郊野樂行精華遊）、山全部都係山、香港山徑日、TimHiking、HK01、U Travel 等。
3. **交叉验证**：尽量 2+ 来源；冲突时取更权威/主流口径，并在备注记录冲突值。
4. **无可靠来源**：保留原值 + 标注「待核」，**绝不编造**。
