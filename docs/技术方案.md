# 技术方案

---

## 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| 形态 | 纯网页应用 | 手机浏览器打开，无需微信环境 |
| 框架 | 无 | Vanilla HTML/CSS/JS，零依赖 |
| 路由 | Hash 路由 | `#/` `#/filter` `#/results` `#/blindbox` `#/hiking-*` `#/park/{id}` `#/trail/{id}` `#/fav-*` |
| 模块 | ES Modules | `<script type="module">` |
| 入口 | `js/app.js` | 统一入口，单行 `<script>` 引入 |
| 字体 | Google Fonts | Josefin Sans + Inter |
| 部署 | 静态服务器 | 任何静态文件服务均可（GitHub Pages 等） |

## 路由设计

| Hash | 页面 ID | 说明 |
|------|------|------|
| `#/` | `page-landing` | 首页（默认） |
| `#/filter` | `page-filter` | 公园筛选页：4个筛选器 + GO!/Reset! + 盲盒 |
| `#/results` | `page-results` | 公园结果页：最多10个公园卡片 |
| `#/blindbox` | `page-blindbox` | 公园盲盒：骰子动画 + 随机推荐 |
| `#/hiking-filter` | `page-hiking-filter` | 徒步筛选页：地區/難度/氛圍/路況 + GO! |
| `#/hiking-results` | `page-hiking-results` | 徒步结果页：最多10条山径卡片 |
| `#/hiking-blindbox` | `page-hiking-blindbox` | 徒步盲盒：骰子动画 + 随机山径 |
| `#/dice-tired` | `page-dice-tired` | 骰子累了（冷却用完时跳转） |
| `#/park/{id}` | `page-park-detail` | 公园详情页（参数化路由） |
| `#/trail/{id}` | `page-trail-detail` | 山径详情页（参数化路由） |
| `#/fav-parks` | `page-fav-parks` | 收藏公园列表 |
| `#/fav-trails` | `page-fav-trails` | 收藏山径列表 |

### 参数化路由

通过 `getHashParam()` 提取 URL 参数：
- `#/park/hkp` → `page-park-detail`，`getHashParam('park')` 返回 `"hkp"`
- `#/trail/maclehose-s1` → `page-trail-detail`，`getHashParam('trail')` 返回 `"maclehose-s1"`

坐标解析辅助函数（用于详情页距离与分享链接）：
- `getHashQuery()` — hash 内 `?lat=...&lng=...` 查询参数
- `getHashCoords()` — hash 内 `@lat,lng` 坐标
- `getSearchCoords()` — server 端 `?ll=lat,lng`（`#` 之前，规避微信截断）

## 状态管理

筛选条件存全局对象 `window.__appState`（仅两个键），并同步 `sessionStorage`：
```js
{
  filters: { region, district, time, parkType, activity },           // 公园筛选（activity 多选数组）
  hikingFilters: { region, district, difficulty, scenery, surface }  // 徒步筛选（scenery 多选数组）
}
```

结果数据用**各页面模块的模块作用域变量**缓存（如 `cachedResults`、`cachedPark`、`trailBlindboxResult`、`currentPage`、`userCoords` 等），`destroy()` 时不清除缓存，确保从详情页返回时内容不变（不重洗牌、盲盒不重投）。

## 匹配算法

### 公园匹配（matcher.js）

```
硬性过滤（AND，全部必须满足）：
  1. 大区匹配（region）
  2. 小区匹配（district，如选择）
  3. 公园类型匹配（parkType）
  4. 时段匹配（bestTime）
  5. 活动匹配（activityTypes，多选 OR：命中任一所选活动即通过）

排序：仅当活动多选 ≥2 项时，按「命中所选活动数」降序排序（命中数相同保持原始顺序）
返回全部匹配结果，翻页在 UI 层控制（无加分、无洗牌）
```

### 山径匹配（trail-matcher.js）

```
硬性过滤（AND，全部必须满足）：
  1. 大区匹配（region）
  2. 小区匹配（district，如选择）
  3. 难度匹配（difficulty）
  4. 氛围匹配（scenery，多选 OR：命中任一所选氛围即通过）
  5. 路况匹配（surface）

排序：仅当氛围多选 ≥2 项时，按「命中所选氛围数」降序排序（命中数相同保持原始顺序）
返回全部匹配结果，翻页在 UI 层控制（无加分、无洗牌）
```
