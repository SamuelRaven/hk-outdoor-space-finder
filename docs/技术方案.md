# 技术方案

---

## 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| 形态 | 纯网页应用 | 手机浏览器打开，无需微信环境 |
| 框架 | 无 | Vanilla HTML/CSS/JS，零依赖 |
| 路由 | Hash 路由 | `#/` `#/filter` `#/results` `#/blindbox` `#/hiking-*` `#/park/{id}` `#/trail/{id}` `#/fav-*` |
| 模块 | ES Modules | `<script type="module">` |
| 入口 | `js/app.js` | 统一入口，单行 `<script>` 引入 |
| 字体 | Google Fonts | Josefin Sans + Inter |
| 部署 | 静态服务器 | 任何静态文件服务均可（GitHub Pages 等） |

## 路由设计

| Hash | 页面 ID | 说明 |
|------|------|------|
| `#/` | `page-landing` | 首页（默认） |
| `#/filter` | `page-filter` | 公园筛选页：4个筛选器 + GO!/Reset! + 盲盒 |
| `#/results` | `page-results` | 公园结果页：最多10个公园卡片 |
| `#/blindbox` | `page-blindbox` | 公园盲盒：骰子动画 + 随机推荐 |
| `#/hiking-filter` | `page-hiking-filter` | 徒步筛选页：地區/難度/氛圍/路況 + GO! |
| `#/hiking-results` | `page-hiking-results` | 徒步结果页：最多10条山径卡片 |
| `#/hiking-blindbox` | `page-hiking-blindbox` | 徒步盲盒：骰子动画 + 随机山径 |
| `#/dice-tired` | `page-dice-tired` | 骰子累了（冷却用完时跳转） |
| `#/park/{id}` | `page-park-detail` | 公园详情页（参数化路由） |
| `#/trail/{id}` | `page-trail-detail` | 山径详情页（参数化路由） |
| `#/fav-parks` | `page-fav-parks` | 收藏公园列表 |
| `#/fav-trails` | `page-fav-trails` | 收藏山径列表 |

### 参数化路由

通过 `getHashParam()` 提取 URL 参数：
- `#/park/hkp` → `page-park-detail`，`getHashParam('park')` 返回 `"hkp"`
- `#/trail/maclehose-s1` → `page-trail-detail`，`getHashParam('trail')` 返回 `"maclehose-s1"`

## 状态管理

全局对象 `window.__appState`：
```js
{
  // 公园筛选状态
  filters: { region, district, time, parkType, activityType },
  results: [...],        // 缓存：从详情页返回不复洗牌
  blindboxResult: {...},

  // 徒步筛选状态
  trailFilters: { region, district, difficulty, scenery, surface },
  trailResults: [...],
  trailBlindboxResult: {...}
}
```

各页面模块通过顶层变量（`cachedResults`）在模块作用域内缓存状态，`destroy()` 时不清除缓存，确保从详情页返回时内容不变。

## 匹配算法

### 公园匹配（matcher.js）

```
硬性过滤（必须满足）：
  1. 大区匹配
  2. 小区匹配（如选择）
  3. 活动类型匹配（parkType + activityTypes）

加分项（影响排序）：
  4. 公园类型匹配 → +2分
  5. 时段匹配 → +1分

排序：总分降序 → 同分组 Fisher-Yates 洗牌 → 取前10
```

### 山径匹配（trail-matcher.js）

```
硬性过滤（必须满足）：
  1. 大区匹配
  2. 小区匹配（如选择）
  3. 难度匹配（不匹配直接跳过）

加分项（影响排序）：
  4. 氛围匹配 → +2分
  5. 路况匹配 → +2分

排序：总分降序 → 同分组 Fisher-Yates 洗牌 → 取前10
```
