## 规则

1. **按 Phase 顺序执行**，完成一个 Phase 后暂停，等确认再继续
2. 每个 Phase 内的步骤也**逐个文件创建**，不要批量产出
3. 遇到数据不确定的地方（如某个公园的 openingHours），标注 `TODO`，不要编造
