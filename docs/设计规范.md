# 设计规范 — 包豪斯风格

> 参考：https://vibe-hub.org/style-bauhaus

---

## 核心原则

**形式服从功能（Form Follows Function）**

- 每个视觉元素必须服务一个目的
- 拒绝装饰、阴影、渐变、模糊
- 深度用重叠色块表达，不用 elevation

---

## 调色板

| 令牌 | 颜色 | 色值 | 用途 |
|------|------|------|------|
| `--color-red` | 镉红 | `#E63946` | 主按钮、强调、删除 |
| `--color-blue` | 普鲁士蓝 | `#1D3557` | 次要按钮、正向、强调 |
| `--color-yellow` | 信号黄 | `#FFB703` | 大面积色块（禁用于正文） |
| `--color-purple` | 皇家紫 | `#6B32A8` | 难度中档、进阶提示 |
| `--color-black` | 纯黑 | `#000000` | 文本、边框、结构线 |
| `--color-white` | 纯白 | `#FFFFFF` | 卡片底色 |
| `--color-bg` | 纸色 | `#F2F2F2` | 页面背景 |

**规则：**
- 单屏不超过3种彩色（难度等级刻度的 5 档配色为语义化例外）
- 黄色只能用于大面积色块（小字对比度不足）
- 不做透明度变化，不用渐变色

## 组件规范

### 按钮
- 矩形，无圆角
- 主按钮：红色底色 + 白色文字
- 轮廓按钮：透明底 + 1px黑边框
- 字号 16px，全大写
- 高度：48px（移动端触摸目标）

### 卡片（公园/山径通用）
- 1px 黑边框 + 半透明白底：`rgba(255,255,255, 0.92)` + `backdrop-filter: blur(2px)`
- 左侧 4px 色条：公园按地区着色 / 山径按难度着色
- 内边距 16px
- 点击整张卡片进入详情页

### 山径卡片
- 难度着色（5 档）：黄（著波鞋就得）/ 蓝（著波鞋都頂得住）/ 紫（著行山鞋穩陣D）/ 红（著行山鞋都腳軟）/ 黑（著咩鞋都打嗮震）
- 显示：名称、路段、时长、距离、简介、💡贴士

### 详情页区块
- 去底色（无背景填充），仅保留彩色左边框
- 左边框颜色交替：红 → 蓝 → 黄 → 黑（循环）
- 活动标签／风景标签：黄色底色 chip

### 收藏星星按钮
- 位置：详情页右上角
- 未收藏：☆ 空心星（黑色 outline）
- 已收藏：★ 实心星（黄色 `#FFB703`）
- 点击切换 + toast 提示

### 结果页统合提示条
- 位于卡片列表顶部，全局只出现一次
- 动态内容根据筛选条件生成（安全提示、注意事项等）

### 输入/选择器
- 1px 黑边框 + 白底
- 高度 48px
- 文字左对齐，箭头右对齐

### Chips / 标签
- 矩形，1px 边框
- 选中态：黄色底色
- 未选中：白底黑字

## 背景几何装饰

每个主页面均有高透明度 Bauhaus 几何背景装饰，提升品牌感。

### 装饰元素类型
- 大圆（黄/红色，`border-radius: 50%`）
- 旋转方块（蓝/红色，`rotate(15deg)`）
- 黄色横条（细长矩形）
- 三角（CSS border 实现）
- 散落圆点（6-10px 直径）
- 斜条纹组（45deg 条纹背景）
- 半环弧线（粗 border + transparent 实现）

### 渲染规则
- `pointer-events: none`（不影响交互）
- `overflow: hidden` on body
- `position: absolute` + z-index 置于内容之下
- 移动端适配：装饰尺寸缩减 30-40%，透明度降低

### 各页面分配
| 页面 | 装饰元素 |
|------|----------|
| 筛选页（公园+徒步） | 大圆 / 旋转方块 / 黄色横条 / 三角 / 圆点 |
| 结果页（公园+徒步） | 蓝色方块 / 斜条纹 / 红色大圆 / 细线 |
| 盲盒页（公园+徒步） | 大圆 / 半环弧线 / 红蓝双色横条 |
| 骰子累了页 | 红色大圆 / 红蓝条纹 |

## 动画规范

### 背景装饰动画
使用 CSS `@keyframes`，仅用 `translate`（不覆盖静态 `rotate`）：

| 动画名 | 变换 | 周期 |
|--------|------|------|
| `float-slow` | translateY | 18-25s |
| `drift` | translateX + translateY | 22-30s |
| `gentle` | 小幅 translate | 20-28s |
| `wide` | 大幅 translate | 25-35s |

所有动画 `ease-in-out`，`infinite` 循环，`alternate` 方向。

### 骰子动画
- 3D CSS cube（`transform-style: preserve-3d`）
- 滚动动画：6 面依次闪现 → 减速 → 定格结果面
- 时长约 2s
