> 共 **101** 个公园

```json
{
  "id": "hkp",
  "nameZh": "香港公園",
  "region": "港島",
  "district": "中西區",
  "openingHours": "06:00-23:00",
  "description": "位於中環的都市綠洲，設有觀鳥園、溫室及人工瀑布，是鬧市中的寧靜角落。",
  "parkType": "主題園林",
  "activityTypes": ["安靜發呆", "散步看景"],
  "bestTime": ["清晨", "上午", "下午"],
  "activityDescriptions": {
    "安靜發呆": "氛圍寧靜清幽，在香港公園的花木之間靜坐片刻，煩惱全消。",
    "散步看景": "香港公園一步一景，氛圍寧靜清幽，園林之美值得細細品味。"
  }

```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 短唯一标识 |
| `nameZh` | string | 中文名称 |
| `region` | enum | `"港島"` `"九龍"` `"新界"` `"離島"` |
| `district` | string | 18区之一 |
| `openingHours` | string | 开放时间（如 `"24小時"` `"06:00-23:00"`） |
| `description` | string | 1-2句中文介绍（分类依据来源） |
| `parkType` | enum | 公园类型（见下） |
| `activityTypes` | string[] | 适合做什么（见下） |
| `bestTime` | string[] | 推荐时段 |
| `activityDescriptions` | object | 每种活动的专属描述文本（key 对应 activityTypes） |
| `features` | string | 公园特色设施/景观（` · ` 分隔，97/101 有真实数据，4 个自动生成） |
| `lat` | number | 纬度（WGS84） |
| `lng` | number | 经度（WGS84） |

### 分类体系

**公园类型（parkType 可选值）：**
- `"海濱長廊"` — 海旁步道、海堤、碼頭、海景公園
- `"市區公園"` — 市中心、社區、居民區內的公園
- `"郊野綠地"` — 郊野、自然生態、濕地、水塘、山頂
- `"主題園林"` — 植物園、動物園、中式/日式園林、花卉主題
- `"休憩花園"` — 小型社區花園、休憩區

**做点什么（activityTypes 可选值）：**
- `"散步看景"` — 有步道、觀景台、海景或山景
- `"親子放電"` — 有兒童遊樂設施或家庭友善空間
- `"運動出汗"` — 有球場、緩跑徑、健身設施
- `"寵物出行"` — 寵物共享公園或可遛狗區域
- `"安靜發呆"` — 清幽、寧靜、適合休憩放鬆

> **数据说明**：parkType 和 activityTypes 基于公园名称和描述文本推断，非康文署官方分类。这样做的原因是康文署网站被墙，无法逐一核实设施清单，但描述性分类可以从已有信息中准确判断。

**推荐时段（bestTime 可选值）：**
- `"清晨"` `"上午"` `"中午"` `"下午"` `"傍晚"` `"夜晚"`

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 短唯一标识 |
| `nameZh` | string | 中文名称 |
| `trailName` | string | 所属径名（4大径之一，或 `""` 表示独立路线） |
| `section` | string | 路段描述（如 `"第一段：北潭涌至浪茄"`） |
| `region` | enum | `"港島"` `"九龍"` `"新界"` |
| `district` | string | 18区之一 |
| `difficulty` | enum | 难度（见下） |
| `scenery` | string[] | 风景类型（见下） |
| `surface` | enum | 路面类型（见下） |
| `lengthKm` | number | 全长（公里） |
| `durationHrs` | number | 预计耗时（小时） |
| `highestPointM` | number | 最高點海拔（米），详情页「⛰️ 海拔」及卡片展示用 |
| `description` | string | 详细中文介绍 |
| `tips` | string | 实用贴士（每条独一无二） |
| `lat` | number | 纬度（WGS84，起点坐标） |
| `lng` | number | 经度（WGS84，起点坐标） |

### 分类体系

**难度（difficulty 可选值）：**
- `"著波鞋就得"` — 轻松易行，适合新手
- `"著波鞋都頂得住"` — 轻中难度，稍有爬升但波鞋可应付
- `"著行山鞋穩陣D"` — 中等难度，需基本体能
- `"著行山鞋都腳軟"` — 高难度，需丰富经验
- `"著咩鞋都打嗮震"` — 极高难度，仅适合资深且无畏高者

**风景类型（scenery 可选值）：**
- `"山海之間"` — 海岸线与山景并存
- `"深山林蔭"` — 密林、山谷、遮荫路线
- `"水庫平湖"` — 水塘、湖泊景观
- `"登頂大景"` — 山顶全景
- `"瀑布溪澗"` — 瀑布、溪流
- `"歷史遺跡"` — 古迹、战地遗址
- `"奇岩怪石"` — 地质奇观、海蚀地貌

**路面类型（surface 可选值）：**
- `"石屎路為主"` — 水泥/柏油路面
- `"山徑為主"` — 天然土路/碎石路
- `"樓梯為主"` — 大量台阶
- `"混合"` — 多种路面交替
