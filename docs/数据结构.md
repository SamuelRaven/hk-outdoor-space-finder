# 数据结构

---

## 公园对象（parks.json）

```json
{
  "id": "hkp",
  "nameZh": "香港公园",
  "region": "港岛",
  "district": "中西区",
  "openingHours": "06:00-23:00",
  "description": "位于中环的都市绿洲，拥有观鸟园、温室及人工瀑布。",
  "facilityType": "both",
  "staticCategories": ["植物及园景", "水景设施", "教育及展览中心"],
  "dynamicCategories": ["儿童游乐设施", "缓跑径/健身径"],
  "bestTime": ["清晨", "上午", "下午"]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 短唯一标识 |
| `nameZh` | string | 中文名称 |
| `region` | enum | `"港島"` `"九龍"` `"新界"` |
| `district` | string | 18区之一 |
| `openingHours` | string | 开放时间 |
| `description` | string | 1-2句中文介绍（分类依据来源） |
| `parkType` | enum | 公园类型（见下） |
| `activityTypes` | string[] | 适合做什么（见下） |
| `bestTime` | string[] | 推荐时段 |

### 分类体系

**公园类型（parkType 可选值）：**
- `"海濱長廊"` — 海旁步道、海堤、碼頭、海景公園
- `"市區公園"` — 市中心、社區、居民區內的公園
- `"郊野綠地"` — 郊野、自然生態、濕地、水塘、山頂
- `"主題園林"` — 植物園、動物園、中式/日式園林、花卉主題
- `"休憩花園"` — 小型社區花園、休憩區

**做点什么（activityTypes 可选值）：**
- `"散步看景"` — 有步道、觀景台、海景或山景
- `"親子放電"` — 有兒童遊樂設施或家庭友善空間
- `"運動出汗"` — 有球場、緩跑徑、健身設施
- `"寵物出行"` — 寵物共享公園或可遛狗區域
- `"安靜發呆"` — 清幽、寧靜、適合休憩放鬆

> **数据说明**：parkType 和 activityTypes 基于公园名称和描述文本推断，非康文署官方分类。这样做的原因是康文署网站被墙，无法逐一核实设施清单，但描述性分类可以从已有信息中准确判断。

**推荐时段（bestTime 可选值）：**
- `"清晨"` `"上午"` `"中午"` `"下午"` `"傍晚"` `"夜晚"`
