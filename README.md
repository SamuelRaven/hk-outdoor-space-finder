我本身就是一个很喜欢大自然和运动的人，就算没有大段空余时间去爬山也一定会挤出小段时间去散步，到处探索。
所以我会挺满足拥有一个这样的推荐程序。即使是仅仅出于自身需求做出来的小东西，但也很有成就感了。
如果有人看到这里，并且感兴趣的话，可以用手机或电脑打开此网站：
https://samuelraven.github.io/hk-outdoor-space-finder/

建议用手机浏览器打开，功能最齐全，可丝滑使用。
1. 用电脑浏览器打开的分享功能效果一般，只能以复制纯链接的形式分享或手机扫码查看。
2. 目前微信不支持分享功能。
3. 用微信打开通过手机浏览器分享的带有距离图标的详情页时，无法同步查看距离图标。

感谢。
